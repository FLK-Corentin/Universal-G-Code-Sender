Fonctionnalités

Modules complémentaires

La plupart des modules complémentaires peuvent être trouvé dans le menu 'Fenêtre > Extensions '.

Assistant de configuration

L'assistant de configuration permet de préparer et calibrer votre CNC. Il vous accompagne notamment pour le réglage des fins de course, du déplacement par pas, du référencement machine et des limites logicielles.

Le guide complet est situé ici.



Digital Read-Out (DRO)

Le Lecteur d'information est le premier retour de l'état de la machine. Il donne l'état de l'appareil, les coordonnées machines, l'activation de la broche. Il peut être utilisé pour réinitialiser des axes individuellement en cliquant sur l’étiquette de l’axe, et a des contrôles dynamiques de position de travail en cliquant sur les numéros de coordonnées.

Pour en savoir plus, c'est ici.



Contrôle de la machine

Le Controle (JOG) est votre outil principal pour contrôler manuellement l’emplacement de vos machines. Il a la possibilité d’utiliser des tailles de pas séparées pour les axes XY et Z en plus d’un mode click-and-hold pour le jogging continu.



Macros personnalisés

Les macros définies par l’utilisateur peuvent être configurées dans le menu des préférences. Une variété de substitutions pratiques sont disponibles pour vous aider à créer des économies de temps parfaitement adaptées à votre flux de travail. Voir le menu d’aide pour plus de détails.


Module Sonde

Un Module de Sonde peut être ouvert depuis le menu extensions. Il permet l'utilisation d'un palpeur pour mesurer une origine en Z, ou pied encore sur des 3 axes.
