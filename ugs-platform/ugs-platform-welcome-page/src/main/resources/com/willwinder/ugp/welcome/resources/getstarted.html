Pour commencer

Bienvenue sur Universal Gcode Sender - Si c’est la première fois que vous utilisez UGS, merci de l’essayer. Cette fenêtre est là pour vous aider à démarrer. Une fois que vous serez à l’aise avec la fonctionnalité d’envoi de base, s’il vous plaît. explore les autres onglets pour en apprendre davantage sur les autres fonctionnalités que ce logiciel a à offrir.

Ouvrir un fichier

Ouvrez votre fichier gcode à partir du Menu Fichier . Une fois le fichier chargé, il y a un nombre de choses que vous pouvez faire avec : inspecter les chemins d’outils depuis le visualiseur, les modifier en utilisant le éditeur intégré, voir le nombre de lignes dans le programme dans la barre d’état. UGS est un excellent moyen de prévisualiser vos parcours d’outils, même si vous n’êtes pas encore prêt à exécuter le programme !

Se Connecter à un controlleur

Lorsque vous êtes prêt à vous connecter à votre machine, la connexion en série peut être configurée dans la barre d’outils en haut du programme. Choisissez votre micrologiciel dans la liste déroulante et configurez le options de série en conséquence. Si vous n’avez pas encore configuré votre contrôleur, vous pourriez être intéressé par assistant de configuration trouvé dans le menu Machine pour vous aider à le configurer.

Une fois connecté, vous pouvez utiliser UGS pour contrôler votre machine. Parmi les bons endroits pour commencer figurent le Jog Controller, envoyer manuellement des commandes dans la console, ou travailler avec le système de coordonnées dans le DRO. Vous pouvez trouver plus d’informations sur les fonctionnalités et comment les utiliser ici .

Lancer un travail

Une fois que vous avez chargé un fichier et établi une connexion à votre contrôleur, le programme peut être exécuté. Ces les icônes de la barre d’outils peuvent être utilisées pour diffuser, interrompre et arrêter le programme.
